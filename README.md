# Multi Telegram Start Bot

Софт для запуска сразу нескольких Telegram-ботов (например, 10+), которые отвечают на `/start` заданным сообщением и кнопкой.

## Что умеет

- Один процесс обслуживает сразу много ботов.
- Для каждого бота можно задать свой текст и кнопку.
- Сообщение быстро меняется через `bots.json` без правки кода.
- При изменении `bots.json` конфиг подхватывается автоматически.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. Скопируйте пример:

```bash
cp bots.example.json bots.json
```

2. Откройте `bots.json` и заполните токены/тексты.

Пример одного бота:

```json
{
  "name": "bot_1",
  "token": "123456:YOUR_BOT_TOKEN",
  "message_text": "👋 Добро пожаловать! Мы запустили новую версию бота.\n\n👇 Перейдите по кнопке ниже.",
  "button_text": "Перейти",
  "button_url": "https://example.com"
}
```

## Запуск

```bash
python bot_manager.py
```

## Как быстро менять сообщение

Просто редактируйте `bots.json`:

- `message_text` — текст ответа на `/start`
- `button_text` — текст кнопки
- `button_url` — ссылка кнопки

Новые значения подхватятся автоматически при следующих сообщениях.
